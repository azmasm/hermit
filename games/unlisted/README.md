# Games with no page yet

[`reports.tsv`](reports.tsv): How it ran reports for games Hermit has no page for, because no build has a profile for them yet. They were built with an untested build, which guesses a profile from the game's own files. Each row names the game and its title ID.

A game that runs well here is a candidate for its own page. Tell others how a game ran with the [How it ran](https://github.com/azmasm/hermit/issues/new?template=how-it-ran.yml) form.
